# Exercícios de interatividade com JavaScript

Páginas para praticar formulários, cálculos e manipulação de elementos no navegador.

## 📌 Funcionalidades

- Lista de tarefas.
- Validação de campos.
- Cálculo de médias, operações e descontos.

## Tecnologias

HTML, CSS e JavaScript.

## 🚀 Como executar

```bash
git clone https://github.com/daviddevdias/database-practice-js.git
cd database-practice-js

```

Abra `V3/index.html` ou `V7/index.html` no navegador. As pastas contêm exemplos independentes de frontend, sem integração com banco de dados.
