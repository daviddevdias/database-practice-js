# Exercícios de interatividade com JavaScript

Coleção de páginas HTML, CSS e JavaScript para praticar manipulação do DOM, formulários e cálculos no navegador.

Apesar do nome do repositório, os exemplos inspecionados são aplicações de frontend: não há integração com banco de dados.

## 📁 Conteúdo

As pastas `V1` a `V7` e `v8` contêm versões independentes. Entre os exemplos estão cadastro de tarefas, validação de nome, cálculo de média, operações aritméticas e desconto.

## 🚀 Executar

```bash
git clone https://github.com/daviddevdias/database-practice-js.git
cd database-practice-js
```

Abra `V3/index.html` ou `V7/index.html` no navegador. Não é necessário instalar pacotes.

Como alternativa, use um servidor local com Python:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000/V3/`.

## Estado e limites

Os exercícios registram versões intermediárias. Não há persistência em banco de dados, autenticação ou testes automatizados. As regras de validação e os intervalos de cálculo ainda precisam de revisão.
